## 주요 보안 시나리오

각 Security 월드는 실제 사이버 위협과 보안 개념을 바탕으로 직접 기획·개발했습니다.

- 프롬프트 인젝션과 생성형 AI 보안
- 디지털 포렌식과 침해 흔적 분석
- 개인정보보호와 안전한 데이터 처리
- 피싱 및 소셜 엔지니어링
- 계정·비밀번호 보안
- 웹 및 네트워크 보안

플레이어가 다양한 위협 상황을 직접 해결하며 보안 원리와 대응 방법을 자연스럽게 익힐 수 있도록 구성했습니다.
